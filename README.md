# Aged Well Senior Care App

**Aged Well Senior Care** is a platform that connects **donors**, **volunteers**, and **admin** for an old age home. This application was developed as a final year project to create a secure and organized system.

## Features
- **Donors** can give food, materials, or cash based on what the admin posts as needed.
- **Volunteers** can pick up urgent tasks and schedule activities to help.
- **Admin** oversees different needs and tracks all contributions.
- **Volunteers receive pop-up alerts** for important tasks after logging in, while keeping resident details confidential.

## Technologies Used
- **Flutter (Dart)** – Android frontend  
- **HTML + CSS** – Web components (if applicable)  
- **Flask (Python)** – Backend API  
- **MySQL** – Database management

---

This project aims to make elderly care coordination easier and encourage community support.
